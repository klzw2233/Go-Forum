# 第二版从搜索开始

第一版（v1.0）覆盖发帖闭环和把圈子开起来所必需的运营动作。第二版按这个顺序：搜索 → 未读 → 锁主题。@、通知、个人页、私信仍后置。

搜索第一刀只做标题和帖正文。可见性和平时看帖一致：会员搜不到停用版、一楼已隐藏的主题、已隐藏的楼；运营者能搜到。停用会员的旧帖会员能搜到。用 SQLite `LIKE`，圈子小，不上 FTS5。

未读按楼号稀疏记录：`thread_reads(member_id, thread_id, last_read_floor)`。没行或楼号落后就是未读。打开主题页（真看见楼）记到当前最大楼号。改帖/改标题/隐藏不改楼号，所以不触发未读。
